The privilege ladder

A model reads one stream of text, and any sentence in it can be phrased as an order. The instruction hierarchy gives each sentence a rank from where it came from, then decides conflicts with one question: does this instruction agree with the levels above it?

Below is a car-dealership assistant with three messages stacked by privilege. The highlighted card is one extra instruction. Move it between rungs, change how it relates to the rungs above, and watch which rule decides what a hierarchy-trained model does. Then switch to a model without the hierarchy and see which cells break.
